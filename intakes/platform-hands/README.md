# Platform Hands intake

Byte-exact portable intake of the Collaboration Platform modular Hands and the smallest proven support closure required by their existing runtime-relative imports.

This is source-preserving intake evidence, not a claim that every Hand is runnable in every host. Each Hand keeps its declared dependencies, permissions, losses and verification ceiling. Intake also grants no CANON, publication or user authority.

The active donor revision and aggregate digest are recorded in `INTAKE_RECEIPT.json`.
